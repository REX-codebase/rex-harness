04Ultra

Competition
before confidence.

Simple asks “does it work?” Ultra asks “how can this be wrong while every green check still passes?”

  • 01
    Contract

    The worker turns the task into machine-checkable obligations.

  • 02
    Candidates

    Up to four start from one immutable pre-run state, each in its own isolated copy.

  • 03
    Adversary

    A separate run whose only job is to find concrete ways the builder’s result is wrong.

  • 04
    Verifier

    Not a model: deterministic Rust re-executes every proof against the real workspace.

  • 05
    Promotion

    Qualified candidates only. One survivor is promoted.
